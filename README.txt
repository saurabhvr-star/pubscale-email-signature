EASIEST DEPLOYMENT ON GITHUB PAGES
1. Upload index.html and the whole assets/ directory into your public repository root.
2. Enable GitHub Pages for main branch / (root).
3. Open your GitHub Pages URL (the generator). It automatically uses the assets/ directory.
4. Employees fill name, designation, location, then click Copy signature and paste in Gmail Settings > General > Signature.
5. Test by sending messages externally and viewing in Gmail and Outlook.

LOCAL TEST
Open signature-generator.html from this folder; it previews the included animation and icons. To copy for use in Gmail while local, first enter the public HTTPS assets folder URL, e.g. https://username.github.io/repo/assets/.

The links for Facebook and X still use GreedyGameMedia because those are the links provided for your company accounts. Update them in SOCIAL_URLS within index.html if renamed.
