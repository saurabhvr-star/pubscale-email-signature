PubScale Gmail signature generator

1. Extract this folder before opening signature-generator.html. The local preview plays pubscale-animation.gif.
2. Ask IT to host pubscale-animation.gif plus instagram.png, linkedin.png, youtube.png, facebook.png and x.png under one HTTPS folder on the company website/CDN.
3. Open generator, enter employee details, asset-folder HTTPS URL and social links.
4. Copy the formatted signature and paste it into Gmail > Settings > See all settings > General > Signature.
5. Send a test message to check animation, graphics, hyperlinks and sizing.

The local image path in the preview does NOT work in email recipients' inboxes; hosting is necessary. The first GIF frame shows the completed logo for clients that do not animate GIFs.
